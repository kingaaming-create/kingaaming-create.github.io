KVM — Private multichannel video production on Windows

KING VIDEO MANAGER is a private desktop application used by its operator to manage their own YouTube channels. This website provides application and privacy information; it does not expose local media, accounts or credentials.

FROM SUBJECT TO PRIVATE UPLOAD
Subject banks → imported scripts and metadata → local VoiceStudio / CosyVoice narration → BVD preparation kits → manual production in Claude → MP4, chapters and credits imported into KVM → private YouTube upload.

YOUTUBE INTEGRATION
KVM uses YouTube API Services with separate Google OAuth authorization and authenticated identity checks for each channel. Features include private uploads, metadata, thumbnails, playlists, publication status and user-requested comments. Future publication requires an explicitly chosen date and confirmation. Comment pinning remains a manual YouTube Studio step where the API does not support it. Optional read-only analytics authorization is separate.

LOCAL DATA AND USER CONTROL
Production files, logs and receipts stay on the operator's computer. OAuth tokens are protected on Windows. Authorized content and API requests are sent to Google/YouTube for the selected functions. Google user data are not sold or used to train generalized AI models. Editorial exchanges with ChatGPT and Claude are performed manually by the operator.
